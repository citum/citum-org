Who it's for

01 — For scholars

You manage sources by hand, still.

You manage sources in a desktop app like Zotero and fix the output by hand. If you have romanized a name and lost the original script, watched "ca. 1650" flatten to a bare year, or forced a shelfmark into a note field — Citum treats those as data, not exceptions.

See the hard cases →

02 — For authors

Keep the workflow. Change the engine.

You write in pandoc, Typst, or Djot and cite with [@key]. Keep that workflow. Citum renders whole manuscripts, outputs LaTeX, Typst, HTML, Djot, and plain text, and publishes PDF via Typst. Existing CSL styles migrate with citum-migrate.

Authoring guides →

03 — For builders

One engine, every surface.

You maintain software that formats citations. Citum is one Rust engine behind every surface — CLI, JSON-RPC server, WASM (@citum/engine on JSR), C FFI — with rendering verified against citeproc-js and biblatex in CI, on a public dashboard.

Get started

Install

curl -fsSL https://github.com/citum/citum-core/releases/latest/download/install.sh | sh # optional: select binaries, e.g. # curl -fsSL … | CITUM_COMPONENTS=all sh # citum, citum-server, citum-migrate

Verifies SHA-256 against the release manifest. Installs to ~/.local/bin. Then: citum --help

cargo install citum --locked

Also available: citum-server (JSON-RPC), citum-migrate (CSL → Citum).

npx jsr add @citum/engine

The engine compiled to WebAssembly, on JSR.

Background

On CSL

CSL mapped what real scholarship needs. Twenty years of styles, processors, and edge cases are the record — and the record shows where an implementation-independent format has to stop. A portable data model must stay simple; the hard cases stay outside. CSL began as a schema and an XSLT processor built for OpenOffice.org; it grew through collaboration — with Simon Kornblith and a wide community — into the standard it is today.

Citum makes the opposite wager: one implementation, built with hindsight. Because there is a single engine, EDTF dates, paired multilingual scripts, and style inheritance can be core semantics instead of extensions. The trade is stated plainly — CSL runs everywhere; Citum runs where Citum runs.1 Every claim of parity is tested, nightly, in public.2
